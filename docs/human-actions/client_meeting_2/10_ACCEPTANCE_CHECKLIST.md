# Acceptance Checklist - Client Meeting #2 Evidence Record

*Per toolkit §5. CM2 (criteria A1–A4, G5) is closed only when this checklist is satisfied by real artifacts. Check boxes only when the artifact exists; attach or reference each.*

## Synchronous meeting record

- [ ] Dated invite / email thread (evidence: ____________)
- [ ] Pre-read as sent, with sent date/time (evidence: ____________)
- [ ] Attendee list (08_ATTENDANCE_RECORD.md completed)
- [ ] Completed feedback form (05_CLIENT_FEEDBACK_FORM.md, verbatim entries)
- [ ] Decision-log entries (06_DECISION_LOG.md rows added)
- [ ] What-changed register entries (07_WHAT_CHANGED_REGISTER.md rows added)
- [ ] Follow-up email sent (09 filled with verbatim content; sent date: ______)
- [ ] Slide/screenshot of exactly what was shown to the client

## Asynchronous-exchange substitute rule

If the touchpoint is asynchronous (email exchange), the meeting-specific items are replaced by:

- [ ] The question set as sent (pre-read + five questions, dated)
- [ ] [client contact]'s **verbatim replies** (the thread itself, preserved unedited)
- [ ] Feedback form (05) completed from those verbatim replies
- [ ] Decision-log and what-changed entries as above
- [ ] Follow-up summary email (09) sent and any corrections received

## Classification gate

- [ ] Team has confirmed (with fellowship staff - see `../fellowship_confirmation/`) whether this touchpoint completes Client Meeting #2, and recorded the answer here: ____________
- [ ] A1 status updated in the compliance tracking only after the above: prior interview = strong client evidence; interview + this documented touchpoint = CM2 complete.

**Integrity note:** if the touchpoint does not occur before July 21, the presentation states honestly that CM2 completion is scheduled/requested and shows these instruments as process evidence - it does not claim the meeting happened.
