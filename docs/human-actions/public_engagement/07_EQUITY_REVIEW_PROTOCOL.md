# Equity Review Protocol

*Prepared 2026-07-19. Operationalizes Report 10 §4 and the peer-question theme (Report 11): how expansion decisions avoid both overbuilding and permanently under-serving lower-adoption communities. The model's equity index exists (e.g., FFX002 0.66, PWC006 0.614, FFX004 0.203) but reflects data only - no community input yet (G3). This protocol pairs the two.*

## Principles

1. **Equity index + engagement evidence, never index alone.** No equity conclusion is presented from the model index without at least one corresponding engagement input (survey, session, or review) - until engagement occurs, equity claims are labeled "model-index only, community input pending."
2. **Equity override on expansion triggers.** Utilization-based expansion triggers must include a documented override so that areas with currently lower EV adoption are not permanently starved: at each review cycle, at least one expansion/seed decision may be justified on equity grounds (index + engagement evidence) even if utilization triggers have not fired. Every use - and every cycle where it is *not* used - is logged with reasons.
3. **Parking displacement is counted and said.** Each port consumes a general space; libraries are parking-sensitive. Site layouts state the count of displaced general and ADA spaces.
4. **Fees are an equity variable.** No fee policy is adopted; any future fee proposal triggers a re-run of this review (fees change both equity and ROI stories) and is flagged as a client/board decision.
5. **Digital access:** no-app/tap-to-pay capability is a procurement requirement; any vendor exception triggers equity review.
6. **Language and disability access** per 04 and 02 are preconditions to calling an engagement round complete.
