# Language Access Plan

*Prepared 2026-07-19. Required practice per Report 10 §3: Spanish at minimum for PWC candidate sites. No translations have been produced yet.*

## Commitments

1. **Spanish is the minimum, not the ceiling.** All public-facing instruments in this package — survey (01), listening-session one-pager (03), privacy notice (05), and any posted signage about the study — are produced in **English and Spanish before any PWC deployment** (Bull Run Library and any other PWC site), and in Spanish for Fairfax City deployments as well.
2. **Survey question 7 is the sensor:** the language-preference question feeds this plan. If responses show meaningful demand for another language at a specific site, instruments for that site are translated into it before the next engagement round. Candidates to watch per regional demographics: Korean, Vietnamese, Arabic, Urdu — driven by data, not assumption.
3. **Translation quality:** human-reviewed translation (bilingual team member, municipal language-access staff, or professional service) — not raw machine output. Reviewer name and date recorded below.
4. **Live sessions:** interpretation offered on request in session announcements, with [X] business days' notice; the host venue's existing language-access services (county/city channels) are used where available.
5. **Plain language first:** English source text is written in plain language so translations stay accurate; no jargon ("Level 2 charger" is explained once, then used).
6. **Accessibility overlap:** large-print versions of all handouts on request; survey online version screen-reader compatible.
