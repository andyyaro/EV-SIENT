## Integrity rule (governs every package)

These packages implement the **process**, not the completion. Per Report 02 §4 ("Integrity rule restated"): team-session and client-touchpoint criteria can only be closed by actually holding the session or touchpoint and documenting it honestly. Accordingly:

1. No client answer, team score, adoption decision, meeting outcome, attendance record, or received datum is filled in anywhere in this directory. Blank fields are blank on purpose and must stay blank until the real event occurs.
2. Every outbound document carries a **"DRAFT - PREPARED 2026-07-19 - NOT SENT"** header. Removing that header is part of the human act of sending, and only the team does that.
3. Each package closes its compliance criteria **only when the human action actually happens and is documented** using the capture instruments provided (feedback forms, logs, registers, signed records). A retrospectively fabricated record would violate the fellowship's intent and this project's evidence discipline.
4. Provisional analytical content (the MCDA matrix, screening-class costs, placeholder capacity values) is labeled as such and is input *to* the human decision, never a substitute for it.
