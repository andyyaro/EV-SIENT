# AI Assistant User Guide

The Future City Fellowship GMU AI Assistant helps approved users explore the project repository and understand the public EV charging planning model.

The assistant is designed for project understanding, not official approval or engineering decision-making.

## Good questions to ask

Useful questions include:

- What is this project trying to solve?
- How does the readiness score work?
- What datasets support the model?
- What do the results mean?
- What limitations does the model have?
- What files support the Tableau exports?
- How should I interpret a site recommendation?
- Which files explain the V2 workflow?
- What assumptions affect right-sizing or future-ready capacity?

## Scope

The assistant is intended to answer questions about:

- project purpose;
- model methodology;
- datasets and source limitations;
- candidate-site screening;
- outputs and reports;
- Tableau/export support;
- assumptions and limitations;
- repository documentation.

## What the assistant is not

The assistant should not be treated as:

- official engineering advice;
- permitting or AHJ approval;
- utility approval;
- procurement guidance;
- legal advice;
- final construction review;
- a place to enter private credentials, API keys, passwords, or sensitive personal information.

## How to use answers responsibly

The assistant can make mistakes or miss context. Check important answers against the cited project files and use the repository documentation as the project source of truth.

For important planning decisions, use the assistant as a starting point for review, not as the final authority.

## Message guidance

Keep questions project-related and reasonably focused. Very long messages may need to be shortened or split into smaller questions.

Good practice:

```text
What files explain the V2 right-sizing scenarios?
```

Better than:

```text
Here is a very long unrelated document. Analyze all of it and make a decision for me.
```
