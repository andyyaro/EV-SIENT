# Tag verification log

**One row per physical tag. An unlogged tag is an unknown tag.**

A tag that is written but not logged cannot later be distinguished from a tag someone else
placed, or from one that has been swapped. Since a locked tag cannot be corrected, the log
is the only record of what is actually deployed.

Fill a row in **as you finish each tag**, not afterwards from memory.

## Status legend

| | |
|---|---|
| **Written** | NFC Tools reported a successful write |
| **Verified** | read back with the app **closed**, URL checked character by character against `tag_payloads.csv`, and the page opened correctly |
| **Locked** | permanently read-only — **irreversible** |
| **Placed** | physically installed, with the facility manager's documented permission |

A tag may be Written and Verified but not Locked; that is a safe intermediate state. A tag
must never be Placed before it is Locked.
