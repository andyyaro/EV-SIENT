# Data Folder

This folder stores input datasets, configuration files, source extracts, baseline snapshots, raw-export notes, and generated local outputs.

## Structure

- [data/inputs/](inputs/) — main model input CSVs
- [data/config/](config/) — model configuration, output manifest, and output-check rules
- [data/source_extracts/](source_extracts/) — small model-ready extracts and public-data upgrade outputs
- [data/baselines/](baselines/) — committed benchmark snapshots
- [data/raw_exports/](raw_exports/) — notes about raw exports not committed to the repo
- `data/outputs/` — generated local outputs ignored by Git

## Main input files

| File | Purpose |
|---|---|
| [data/inputs/real_sites_v1.csv](inputs/real_sites_v1.csv) | Stable V1 candidate-site dataset. |
| [data/inputs/real_sites_v2.csv](inputs/real_sites_v2.csv) | Active V2 expansion-planning candidate-site dataset. |
| [data/inputs/v2_port_sizing_scenarios.csv](inputs/v2_port_sizing_scenarios.csv) | Active V2 port-sizing scenario assumptions. |
| [data/inputs/sites_demo.csv](inputs/sites_demo.csv) | Small starter/demo dataset. |
| [data/inputs/new_sites_template.csv](inputs/new_sites_template.csv) | Template for future candidate-site rows. |

Use [docs/SITE_SCREENING_CHECKLIST.md](../docs/SITE_SCREENING_CHECKLIST.md) and [docs/ADDING_NEW_SITES_GUIDE.md](../docs/ADDING_NEW_SITES_GUIDE.md) before copying new rows into a real model input file.

For V2 expansion work, also use [docs/V2_PUBLIC_DATA_UPGRADE_WORKFLOW.md](../docs/V2_PUBLIC_DATA_UPGRADE_WORKFLOW.md) before treating a new candidate as serious.

## Config files

| File | Purpose |
