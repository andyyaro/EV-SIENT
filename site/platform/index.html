EV charging site readiness

Twelve candidate sites in Northern Virginia, screened for whether public charging could make sense — and if so, how much to start with.

Nothing here is approved, funded or permitted. Electrical capacity is a placeholder at all twelve sites — nobody has confirmed the service could support chargers. Demand is modelled, not measured. Costs are screening estimates for comparison, never budgets or quotes.

    Which engine produced what

    Four things can compute in this project and they are never treated as interchangeable.

    • Python The single producer. Every number on this page.
    • MathWorks MATLAB Has executed the model — 49 tests, a 120-row batch — but only against a synthetic fixture. It has never seen these twelve sites.
    • GNU Octave Not MATLAB. A syntax and smoke tier. The fail-closed capacity guard does not fire under it, so it may never make a feasibility statement.
    • Simulink A block diagram built from the model source. Built, never simulated; no number derives from it.

    Field data

    No field observations have been received.

    The loop that ingests them is built and tested: a utility load study or a month of charger logs would upgrade a site's capacity from placeholder to verified, raise its data confidence, and make its expansion trigger evaluable. Until something arrives, this stays empty — which is the honest state, not an omission.

    Where this number comes from

    Screening-class planning study. Not an engineering design, not a utility confirmation, not a fire or accessibility review, and not a commitment by any government body.
