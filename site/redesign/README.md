# Redesigned public site (futurecity.andyyaro.com)

A complete redesign of the public pages in `site/www/`, built from the HIG Native design system
(an unofficial web interpretation of Apple's Human Interface Guidelines). It is a separate site:
`site/www/` and everything it is served from are unchanged.

Live at https://futurecity.andyyaro.com (noindex). See any page at every device size at
https://futurecity.andyyaro.com/devices.html.

## Layout

| Path | What it is |
|---|---|
| `www/` | The static site: flat HTML pages, no build step, no frameworks, no web fonts |
| `film.html`, `film/` (live only) | The launch film's watch page and files, published by `media/launch-film/deploy/publish.sh`, not from `www/`. `tools/deploy.sh` excludes both from its `--delete` syncs, so a site deploy leaves the film alone |
| `www/css/tokens.css` | Generated from the design system's `tokens.json` (four themes: light, dark and both increased-contrast variants) |
| `www/css/base.css`, `www/css/hig.css`, `www/js/icons.js` | Copied from the design system (foundations, component styles, icon glyphs) |
| `www/css/site.css`, `www/js/app.js`, `www/js/theme.js` | The shell: navigation, footer, data loading, shared controls, system theme mapping |
| `www/css/pages/`, `www/js/pages/` | One stylesheet and script per page |
| `www/vendor/` | `amazon-cognito-identity-js` (Apache-2.0, same file as `site/www/vendor`) and `qrcode-generator` 1.4.4 (MIT), served from this site |
| `www/data/sites.json` | Ranks, scores, port plans, waits, horizons, costs and emissions. Generated by `tools/build_sites.py` from the authoritative contract `data/contract/v3` (DEC-027); rank, score and tier come from the canonical milestone2_v3 results, and the mean wait and deferred-case cost from the model's own functions, cross-checked against the contract. Every official port total on the site is summed from here. No inputs (DEC-016) |
| `www/data/scoring.json` | The score weights and each site's score split into its four weighted parts, in points. Generated by `tools/build_scoring.py` from `src/fcf_m2/scoring.py` and the canonical milestone2_v3 results; refuses to write if a score disagrees with `sites.json` |
| `www/data/stability.json` | Rank stability: one weight at a time, 2,000 random weightings and the unconfirmed-capacity range. Generated by `tools/build_stability.py` from `reports/rank-stability/rank_stability_reference_12_sites.json` (`src/fcf_m2/stability.py`); refuses to write if it disagrees with `sites.json` or `scoring.json`. Pages show none of it unless `status` is `"final"` |
| `www/data/versions.json` | Which ranking the official port plan follows (`milestone2_v3` since DEC-027), the official scenario sweep and baseline check where the contract provides them (v3 provides neither, so both are null), and the earlier `legacy_v2` result (25 / 48), always shown apart and labelled "Earlier result (legacy_v2)". `build_sites.py` refuses to write if it disagrees with the contract |
| `tools/` | `gen_tokens.py`, `build_sites.py`, `build_scoring.py` and `build_stability.py` (write `www/data/sites.json`, `scoring.json` and `stability.json`; `--check` verifies them), `qa.py` (static checks), `matrix.py` (every page at 16 viewports in Chromium and WebKit, light and dark), `deploy.sh` |

## Information architecture

Results: Overview, Sites (split view, deep links like `sites.html#FFX004`), Compare, Outlook,
Explore Data (Tableau views, loaded only on request). Approach: Method, Standards. Project:
Assistant (its own page here, see below), About, Privacy. Phones get a
floating tab bar with a More page; widths of 1024px and up get a floating sidebar.

## Assistant

`assistant.html` is a native client for the existing assistant service; it does not link to the
earlier site. Sign-in uses the same Cognito user pool, with every step handled on the page: new
password, authenticator enrollment (QR code, "Add to Authenticator App" link and setup key),
6-digit codes, and forgot password. Tokens live in `sessionStorage`, so a session lasts for one
tab. Questions go straight from the browser to the HTTP API `POST /chat` (same body and limits as
the earlier client). The call is not proxied through CloudFront because the service rate-limits
by source IP.

For this, `https://futurecity.andyyaro.com` was added to the HTTP API's CORS `AllowOrigins`
(alongside the two existing origins, which are unchanged), and the response headers policy's
`connect-src` allows `cognito-idp.us-east-1.amazonaws.com` and the API host.

## Checks and deploy

```bash
python3 site/redesign/tools/qa.py site/redesign/www
PYTHONPATH=src python3 site/redesign/tools/build_sites.py --check
PYTHONPATH=src python3 site/redesign/tools/build_scoring.py --check
python3 site/redesign/tools/build_stability.py --check
(cd site/redesign/www && python3 -m http.server 8765) &
python3 site/redesign/tools/matrix.py http://localhost:8765 /tmp/matrix-shots --shots
# MATRIX_QUICK=1 for 6 viewports; MATRIX_PAGES=assistant.html,about.html for chosen pages
site/redesign/tools/deploy.sh site/redesign/www
```

`matrix.py` flags links under 24px. Rows in the design system's lists stretch their link over the
whole row with a pseudo-element, so those flags are expected; tap targets were confirmed by hit
testing.
